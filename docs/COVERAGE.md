# Coverage

Every situation I designed this kiosk for, whether I handled it, how, and how you can check it yourself. This file is the one place that holds the status of each item. The README and the other docs link here instead of repeating it.

Every status comes from a run I did on 2026-11-02 on Node 24.22.2:

- `pnpm typecheck`
- `pnpm lint`
- `pnpm test` (108 tests)
- `pnpm test:e2e` (18 tests)
- `docker compose up`
- a few manual probes against the running stack

I didn't upgrade a status from reading the code alone.

## Status values

| Status | Meaning |
|---|---|
| **Handled** | Built, and a test or a run in this pass shows it working. For the traps (T), it means I avoided the trap. |
| **Partial** | Part of it works. The row says which part is missing. |
| **Not handled: by choice** | I left it out on purpose. The row says why. |
| **Not handled: out of time** | I wanted it and ran out of time. The row says what it would take. |
| **Unverified** | It exists, but I couldn't prove it in this run. |

Test references read `file › test name`. API tests are in `apps/api/test/`, client unit tests in `apps/web/test/`, contract tests in `packages/shared/test/`, browser tests in `e2e/`.
